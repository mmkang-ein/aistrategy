# Structured Implicit Experimental Context for Neural Network Reproducibility Failure Classification and Prediction: An LLM-Based Unstructured Information Integration Framework

---

## Abstract

신경망 실험 재현성 실패는 AI 연구 신뢰성의 근본적 위협으로, 70% 이상의 연구자가 타인의 실험 재현에 실패한다. 본 연구는 재현성 실패 원인을 (1) 정형 메타데이터 누락, (2) 비정형 암묵적 맥락 손실, (3) 확률적 변동 미정량화로 분류하고, LLM 기반 비정형 정보 구조화 프레임워크('repro-guard')를 제안한다. 100건의 실패 사례 귀납적 분류 체계 수립과 통제된 대조 실험을 통해 문서화 완전성 향상(Cohen's d ≥ 0.5) 및 재현성 성공률 향상(r ≥ 0.4)을 실증한다.

## 1. Introduction

### 1.1 연구 배경 및 동기

인공지능 및 컴퓨터비전 분야의 급속한 발전과 함께, 학술 공동체 내에서 **재현성 위기(Reproducibility Crisis)** 가 심각한 문제로 부상하고 있다 [1]. Nature의 대규모 조사에 따르면 과학 전반에서 70% 이상의 연구자가 타인의 실험을 재현하는 데 실패하며 [2], 기계학습 및 딥러닝 분야에서 이 문제는 더욱 심화된다. NeurIPS 및 ICML의 재현성 챌린지 결과는 최상위 학술지에 게재된 논문조차 독립적 재현이 어렵다는 사실을 반복적으로 확인시켜 준다 [3].

재현성 실패의 원인은 단순히 코드나 데이터의 미공개에 그치지 않는다. 연구자들이 암묵적으로 공유하는 실험 맥락—코드 주석에 담긴 구현 의도, 논문 본문에 산재된 세부 사항, GitHub Issue/PR 대화, Slack 및 Discord 협업 기록—은 현재의 실험 추적 도구(MLflow, Weights & Biases 등)가 체계적으로 캡처하지 못하는 **암묵적 지식(Tacit Knowledge)** 의 영역에 속한다 [4]. 이러한 비정형 정보의 손실은 정형 메타데이터 누락이나 확률적 변동 미정량화와 함께 재현성 실패의 핵심 원인을 구성한다.

한편, 대형 언어 모델(LLM)의 등장은 비정형 텍스트를 구조화된 정보로 변환하는 새로운 가능성을 열었다 [5]. GPT-4o, Claude 3.5 등 최신 LLM은 자연어 이해와 정보 추출 능력에서 전례 없는 성능을 보이며, 이를 실험 문서화 자동화에 적용하려는 시도가 증가하고 있다 [6]. 그러나 LLM의 환각(hallucination) 오류, 측정 타당도 미확립, 도메인별 재현성 기준의 부재 등 방법론적 과제가 해결되지 않은 채 남아 있다.

본 연구는 이러한 배경에서 출발하여, **LLM 기반 비정형 암묵적 맥락 구조화를 통한 신경망 재현성 실패 원인 분류 및 예측 프레임워크**를 제안한다. 특히 기존 도구와의 명확한 기능적 차별화, 귀납적 실패 원인 분류 체계 수립, 그리고 인과 경로 분리 실험을 통한 LLM 기여분의 독립적 정량화를 핵심 목표로 삼는다.

### 1.2 핵심 기여 (Contributions)

본 연구의 주요 기여는 다음 네 가지로 요약된다:

1. **귀납적 재현성 실패 원인 분류 체계(Taxonomy)**: 100건의 공개 재현성 실패 사례를 혼합 방법론(정성 코딩 + 빈도 분석)으로 분석하여, 사전 가이드라인이 아닌 실증 데이터 기반의 5범주 분류 체계를 최초로 수립한다.

2. **LLM 기반 비정형 맥락 구조화 파이프라인**: 코드 주석, 논문 텍스트, 협업 대화 등 기존 도구가 캡처하지 못하는 암묵적 실험 맥락을 구조화된 메타데이터로 변환하는 'repro-guard' 프레임워크를 개발한다.

3. **문서화 완전성 점수의 측정 타당도 확립**: 평가 루브릭의 명시적 조작화, 독립 평가자 간 신뢰도(Krippendorff's α ≥ 0.7), LLM 환각 필터링을 포함한 엄밀한 측정 체계를 구축한다.

4. **인과 경로 분리 실험**: 문서화 완전성 단독 효과와 LLM 추가 효과를 독립적으로 정량화하는 통제된 대조 실험 설계를 통해 LLM의 실질적 기여분을 과학적으로 검증한다.

## 2. Related Work

### 2.1 딥러닝 모델 테스팅 및 검증 방법론

딥러닝 모델의 신뢰성 평가는 단순 정확도를 넘어 다양한 환경에서의 일반화와 견고성을 체계적으로 검증하는 방향으로 진화하고 있다 [7]. 로컬 견고성 분석(Local Robustness Analysis), 일반화 능력 메트릭, 교차 검증 기반 성능 평가 등이 표준적 방법론으로 자리잡고 있으며 [8], 특히 적대적 견고성(Adversarial Robustness) 평가는 컴퓨터비전 분야에서 중요한 연구 주제로 부상하였다 [9].

Goodfellow et al. [10]의 FGSM(Fast Gradient Sign Method) 이후, 화이트박스/블랙박스 공격 방법의 발전과 함께 23개 이상의 다양한 평가 지표가 제시되었다 [11]. 이러한 견고성 평가 지표의 다양성은 모델 테스팅의 복잡성을 반영하는 동시에, 표준화된 평가 프레임워크의 필요성을 강조한다.

### 2.2 AI 시스템 평가 지표: 일반화와 견고성

AI 시스템 평가는 단순 정확도를 넘어 새로운 데이터에 대한 성능(일반화)과 데이터 분포 변화에 대한 안정성(견고성)을 동시에 측정하는 방향으로 발전하고 있다 [12]. Hendrycks & Dietterich [13]의 ImageNet-C 벤치마크는 자연적 분포 변화에 대한 견고성을 체계적으로 평가하는 선구적 연구로, 이후 다양한 도메인에서 유사한 접근이 시도되었다.

그러나 이러한 평가 지표들의 재현성 문제는 여전히 미해결 과제로 남아 있다. 동일한 모델, 동일한 데이터셋을 사용하더라도 구현 세부사항의 차이로 인해 성능 수치가 유의미하게 달라지는 현상이 반복적으로 보고된다 [14].

### 2.3 실험 추적 도구와 재현성

MLflow [15], Weights & Biases [16], DVC [17] 등 현재의 실험 추적 도구들은 정형 메타데이터(하이퍼파라미터, 모델 아키텍처, 성능 지표)의 자동 캡처에 특화되어 있다. 이들 도구는 실험 관리의 효율성을 크게 향상시켰으나, 연구자의 의사결정 과정에 담긴 암묵적 맥락—왜 특정 하이퍼파라미터를 선택했는지, 어떤 예비 실험이 실패했는지, 팀 내 논의에서 어떤 통찰이 도출되었는지—은 여전히 캡처하지 못한다 [18].

Pineau et al. [19]의 재현성 체크리스트(ML Reproducibility Checklist)는 이 문제를 인식하고 표준화된 보고 형식을 제안하였으나, 체크리스트 준수 여부의 자동화된 검증 메커니즘이 부재하다는 한계가 있다.

### 2.4 LLM의 과학적 문서화 지원

최근 LLM을 과학 문서화 및 정보 추출에 활용하는 연구가 증가하고 있다. Beltagy et al. [20]의 SciBERT, Gururangan et al. [21]의 도메인 적응 사전학습 등이 과학 텍스트 이해의 기반을 마련하였으며, GPT-4 기반 과학 논문 요약 및 메타데이터 추출 연구들이 유망한 결과를 보이고 있다 [22]. 그러나 LLM의 환각 오류가 과학적 정확성을 요구하는 맥락에서 심각한 위험 요소임이 지적되며 [23], 전문가 검토 단계를 포함한 인간-AI 협업 파이프라인의 필요성이 강조된다.

### 2.5 테스트 데이터셋 편향과 일반화

기계학습 모델의 신뢰성을 보장하기 위해서는 테스트 데이터셋의 편향을 체계적으로 평가해야 한다 [24]. 단순 편향 탐지를 넘어 데이터 수집부터 평가까지 ML 파이프라인 전반에 걸친 편향 분석이 요구되며 [25], 이러한 데이터셋 편향은 재현성 실패의 중요한 원인 중 하나로 기능한다.

### 2.6 본 연구와의 차별점

기존 연구들과 비교하여 본 연구는 다음과 같은 차별점을 갖는다:

| 구분 | 기존 연구 | 본 연구 |
|------|-----------|---------|
| 재현성 실패 원인 분석 | 사전 정의된 범주 사용 | 100건 실패 사례 귀납적 분류 |
| LLM 활용 영역 | 정형 정보 처리 | 비정형 암묵적 맥락 구조화 특화 |
| 측정 타당도 | 단일 평가자 또는 미명시 | Krippendorff's α ≥ 0.7 기준 다중 평가자 |
| 인과 추론 | 상관관계 분석 | 인과 경로 분리 실험 설계 |
| 도메인 적용 | 단일 도메인 | 다중 도메인 + 의료 AI 규제 연결 |

## 3. Methodology

### 3.1 연구 설계 개요

본 연구는 6단계 순차적 연구 설계를 따른다 (Figure 1). 각 단계는 이전 단계의 결과를 기반으로 하며, 파일럿 연구를 통한 사전 타당도 검증이 대규모 실험에 선행된다.

```
Phase 0: 분류 체계 수립 (3개월)
    ↓
Phase 1: 파일럿 연구 - 예측 타당도 검증 (2개월)
    ↓
Phase 2: MVP 개발 - 경량 자동 캡처 모듈 (2개월)
    ↓
Phase 3: LLM 비정형 맥락 구조화 모듈 (3개월)
    ↓
Phase 4: 불확실성 정량화 모듈 (2개월)
    ↓
Phase 5: 통제된 대조 실험 (3개월)
    ↓
Phase 6: 의료 AI 도메인 심화 (2개월)
```

**Figure 1**: 연구 단계별 순차 설계도

### 3.2 Phase 0: 재현성 실패 원인 분류 체계 수립

#### 3.2.1 데이터 수집

Papers with Code Reproducibility Challenge, NeurIPS 재현 트랙(2019–2023), ICML 재현 트랙(2020–2023)에서 공개된 재현성 실패 사례 100건을 수집한다. 선정 기준:

- 원 논문과 재현 시도 보고서가 모두 공개된 사례
- 재현 성공/실패 여부가 명시적으로 보고된 사례
- 컴퓨터비전, NLP, 시계열 예측, 의료 AI 도메인 균형 포함

#### 3.2.2 혼합 방법론 분석

**정성 코딩 단계**: 3인의 독립 코더가 각 실패 사례의 원인을 개방 코딩(Open Coding) → 축 코딩(Axial Coding) → 선택 코딩(Selective Coding)의 근거이론(Grounded Theory) 절차로 분석한다. 코더 간 불일치는 토론 합의 방식으로 해결한다.

**빈도 분석 단계**: 도출된 코드의 출현 빈도, 공출현 패턴, 도메인별 분포를 분석하여 주요 범주를 귀납적으로 확정한다.

**가설적 5범주 분류 체계** (실증 분석 후 수정 가능):

| 범주 | 정의 | 예시 지표 |
|------|------|-----------|
| C1: 정형 메타데이터 누락 | 랜덤 시드, 하이퍼파라미터 등 미보고 | 누락 필드 수 |
| C2: 비정형 암묵적 맥락 손실 | 구현 의도, 예비 실험 결과 미기록 | 암묵적 결정 수 |
| C3: 확률적 변동 미정량화 | 단일 실행 결과만 보고 | 신뢰 구간 미제공 |
| C4: 환경 의존성 | 소프트웨어 버전, 하드웨어 차이 | 환경 명세 완전성 |
| C5: 데이터 편향 | 테스트셋 분포 편향 | 편향 스코어 |

#### 3.2.3 문서화 완전성 점수 측정 타당도 확립

**핵심 방법론적 보완사항**: 리뷰어 피드백을 반영하여 문서화 완전성 점수의 측정 타당도를 다음과 같이 확립한다.

**루브릭 조작화**: 각 범주별 세부 평가 항목을 4점 척도(0: 완전 누락, 1: 부분적, 2: 대부분 충족, 3: 완전 충족)로 정량화한다. 총 점수는 가중 합산으로 산출하며, 가중치는 Phase 0 빈도 분석 결과를 반영한다.

**평가자 간 신뢰도**: 최소 2인의 독립 전문가 평가자가 루브릭을 적용하며, Krippendorff's α ≥ 0.7을 수용 기준으로 설정한다. 초기 α < 0.7인 경우, 불일치 항목에 대한 정의 명확화 및 예시 추가 후 재평가한다.

**LLM 환각 필터링**: LLM이 추출한 정보는 3단계 검증을 거친다: (1) 원문 인용 확인(Citation Verification), (2) 도메인 전문가 샘플 검토(전체의 20% 무작위 추출), (3) 논리적 일관성 자동 검사(규칙 기반 필터).

**도메인별 재현성 기준 차별화**: ±2% 단일 기준 대신 도메인별 기준을 적용한다:

| 도메인 | 지표 | 재현성 성공 기준 |
|--------|------|-----------------|
| 이미지 분류 | Top-1 Accuracy | ±1.0%p |
| NLP (GLUE) | 복합 점수 | ±1.5%p |
| 시계열 예측 | MAE/RMSE | ±3.0% |
| 의료 AI | AUROC | ±0.02 |

### 3.3 Phase 1: 파일럿 연구 - 재현성 리스크 지표 예측 타당도 검증

20개 공개 실험(ImageNet 분류 5건, GLUE 벤치마크 5건, 시계열 예측 5건, 의료 AI 5건)을 대상으로 다음 절차를 수행한다:

**Step 1**: 후보 리스크 지표 측정
- 견고성 취약 샘플 비율(Fragile Sample Ratio, FSR): 소규모 입력 변동에 예측이 변경되는 샘플의 비율
- 테스트셋 편향 스코어(Test Set Bias Score, TSBS): 훈련/테스트 분포 간 Maximum Mean Discrepancy
- 문서화 완전성 점수(Documentation Completeness Score, DCS): 루브릭 기반 정량화

**Step 2**: 독립적 재현 시도 및 레이블링
각 실험에 대해 독립 연구자 3인이 재현을 시도하고, 다수결로 성공/실패를 레이블링한다.

**Step 3**: 예측 타당도 검증
AUC-ROC ≥ 0.65를 충족하는 지표만 대시보드에 통합한다. 로지스틱 회귀 및 Random Forest로 예측 모델을 구축하고 Leave-One-Out 교차검증으로 평가한다.

G*Power 분석 기반 최소 표본 크기:
- 유의수준 α = 0.05
- 검정력 1-β = 0.80
- 효과크기 f = 0.25 (중간 효과)
- 그룹당 최소 52회 재현 시도
- 총 최소 208회 재현 시도 (4조건 × 52회)

#### 3.7.3 인과 경로 분리 검증

조건 D('체크리스트 강제')를 통해 문서화 완전성 향상의 단독 효과를 추정하고, 조건 C와의 차이를 LLM의 순수 기여분으로 정량화한다:

```
LLM 기여분 = Effect(C) - Effect(D)
문서화 완전성 효과 = Effect(D) - Effect(B)
```

def load_data(filepath=None):
    """

    return df


def preprocess_data(df):
    """
    데이터 전처리 함수
    - 결측치 처리
    - 이상치 탐지 및 제거
    - 정규화
    """
    print("\n[전처리 시작]")
    print(f"  원본 데이터 shape: {df.shape}")

    # 결측치 확인
    missing = df.isnull().sum()
    if missing.any():
        print(f"  결측치 발견:\n{missing[missing > 0]}")
        df = df.fillna(df.median(numeric_only=True))  # 수치형: 중앙값으로 대체
        df = df.fillna(df.mode().iloc[0])              # 범주형: 최빈값으로 대체
    else:
        print("  결측치 없음")

    # 수치형 컬럼 선택
    numeric_cols = df.select_dtypes(include=[np.number]).columns.tolist()

    # 이상치 탐지 (IQR 방법)
    outlier_mask = pd.Series([True] * len(df), index=df.index)
    for col in numeric_cols:
        Q1 = df[col].quantile(0.25)
        Q3 = df[col].quantile(0.75)
        IQR = Q3 - Q1
        lower = Q1 - 1.5 * IQR
        upper = Q3 + 1.5 * IQR
        col_mask = (df[col] >= lower) & (df[col] <= upper)
        outlier_mask = outlier_mask & col_mask

    n_outliers = (~outlier_mask).sum()
    print(f"  이상치 샘플 수: {n_outliers}")
    df_clean = df[outlier_mask].copy()
    print(f"  전처리 후 shape: {df_clean.shape}")

    # 수치형 컬럼 정규화 (StandardScaler)
    scaler = StandardScaler()
    df_scaled = df_clean.copy()
    df_scaled[numeric_cols] = scaler.fit_transform(df_clean[numeric_cols])

    print("[전처리 완료]")
    return df_clean, df_scaled, scaler

def group_comparison(df, group_col='group', value_col='target'):
    """
    그룹 간 비교 분석
    - 일원분산분석(One-way ANOVA)
    """
    if group_col not in df.columns or value_col not in df.columns:
        print(f"  [경고] '{group_col}' 또는 '{value_col}' 컬럼이 없습니다.")
        return None

    groups = df[group_col].unique()
    group_data = [df[df[group_col] == g][value_col].values for g in groups]

    # ANOVA 검정
    f_stat, p_value = stats.f_oneway(*group_data)
    print(f"\n[그룹 비교 - One-way ANOVA]")
    print(f"  그룹: {list(groups)}")
    print(f"  F-통계량: {f_stat:.4f}")
    print(f"  p-value : {p_value:.4f}")
    if p_value < 0.05:
        print("  결론: 그룹 간 유의미한 차이 있음 (p < 0.05)")
    else:
        print("  결론: 그룹 간 유의미한 차이 없음 (p >= 0.05)")

    return {'f_stat': f_stat, 'p_value': p_value, 'groups': groups}


def pca_analysis(df_scaled, n_components=2):
    """
    주성분 분석 (PCA)
    - 차원 축소 및 분산 설명력 확인
    """
    numeric_cols = df_scaled.select_dtypes(include=[np.number]).columns
    pca = PCA(n_components=min(n_components, len(numeric_cols)))
    pca_result = pca.fit_transform(df_scaled[numeric_cols])

    explained_var = pca.explained_variance_ratio_
    print(f"\n[PCA 분석]")
    for i, var in enumerate(explained_var):
        print(f"  PC{i+1} 설명 분산: {var:.4f} ({var*100:.2f}%)")
    print(f"  누적 설명 분산: {explained_var.sum():.4f} ({explained_var.sum()*100:.2f}%)")

    pca_df = pd.DataFrame(
        pca_result,
        columns=[f'PC{i+1}' for i in range(pca_result.shape[1])],
        index=df_scaled.index
    )
    return pca_df, pca, explained_var
